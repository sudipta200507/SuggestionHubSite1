# Class Notes Hub

A lightweight browser-based academic resource portal for organizing and downloading subject-wise study notes.

## Overview

The project provides a simple interface where students can select a subject and access the corresponding study material.

## Current Subjects

- Python
- DBMS
- Computer Organization and Architecture
- Discrete Mathematics

## Architecture

`text
HTML UI
   ↓
Subject Selection
   ↓
Static Note Mapping
   ↓
Browser Download / Navigation
`

## Implementation

The application is intentionally simple:

- Single-page HTML interface
- Tailwind CSS via CDN
- Client-side JavaScript
- Static note paths

Missing note files are handled explicitly instead of silently failing.

## Status

**Small academic utility / learning project.**

Future improvements could include search, categories, upload management, authentication, and a backend resource API.
